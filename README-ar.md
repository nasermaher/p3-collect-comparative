# P3CC (P3 Collect-Comparative)

## نَظْرَة عامة

P3CC هي أداة مساعدة مبنية على بايثون مصممة لمعالجة ملفات `.p3` وإثرائها ببيانات من جداول بيانات Excel. تقوم بأتمتة جمع ومقارنة المعلومات المتعلقة بالبطاقات، ودمج تفاصيل مثل أسماء حاملي البطاقات، وأرقام الهُوِيَّة الوطنية، وأرقام الهواتف المحمولة، وغيرها من البيانات الخاصة بالمِلَفّ الشخصي مباشرةً في ملفات الإخراج `.p3`.

يتكون البرنامَج من (ثلاثة) ملفات بايثون رئيسية:
- `main.py`: نقطة الدخول للتطبيق، تنسق اختيار المِلَفّات، ومعالجة البيانات، وتوليد الإخراج.
- `utils.py`: يحتوي على دوال مساعدة بحتة لتحويل البيانات، ومعالجة المِلَفّات، واكتشاف المِلَفّات الشخصية، وبناء النصوص. تم تصميمه لإعادة الاستخدام وقابلية الاختبار.
- `config.py`: يركز جميع المعلمات القابلة للتكوين، مثل الترميز، وامتدادات المِلَفّات، والعلامات الثنائية، وتوقيعات المِلَفّات الشخصية، وتعيينات الحقول. تم تصميم هذا المِلَفّ ليتم تعديله بسهولة دون لمس المنطق الأساسي.
- `exceptions.py`: يحدد فئات الاستثناءات المخصصة لظروف خطأ محددة داخل التطبيق، مما يسمح بمعالجة أخطاء أكثر دقة وتصحيح أخطاء أوضح.

## الميزات

- **المعالجة القائمة على المِلَفّ الشخصي**: يكتشف تلقائيًا بنية ملف Excel (مثل 'Yalla', 'Zamalek', 'Classic') ويطبق تعيين البيانات الصحيح.
- **بحث فعال عن البيانات**: يستخدم Pandas DataFrames مع عمليات بحث مفهرسة لاسترجاع سريع لبيانات البطاقة.
- **تطبيع الأحرف العربية**: يتضمن معالجة قوية للأحرف والأرقام العربية.
- **تعيين الحقول القابل للتكوين**: قابل للتوسيع بسهولة لدعم أعمدة Excel الجديدة أو علامات الإخراج عبر `config.py`.
- **تتبع التقدم**: يوفر شريط تقدم للعمليات طويلة الأمد.
- **التسجيل (Logging)**: تسجيل مفصل لتحسين التتبع وتصحيح الأخطاء.

## كيفية الاستخدام

1.  **المتطلبات الأساسية**:
    *   تأكد من تثبيت Python 3.x.
    *   قم بتثبيت المكتبات المطلوبة عن طريق تشغيل:
        ```bash
        pip install -r requirements.txt
        ```

2.  **إعداد ملفاتك**:
    *   ضع ملفات المصدر `.p3` الخاصة بك في مجلد مخصص.
    *   جهز جدول بيانات Excel الخاص بك (`.xlsx` أو `.xls`) بالبيانات التي ترغب في دمجها.

3.  **تشغيل البرنامج**:
    *   انتقل إلى دليل المشروع في محطتك الطرفية (Terminal).
    *   قم بتشغيل ملف `run.bat`:
        ```bash
        run.bat
        ```
    *   بدلاً من ذلك، يمكنك تشغيل `main.py` مباشرة:
        ```bash
        python main.py
        ```

4.  **اتبع التعليمات**:
    *   سيطلب منك البرنامج أولاً تحديد المجلد الذي يحتوي على ملفات `.p3` الخاصة بك.
    *   بعد ذلك، سيطالبك بتحديد ملف بيانات Excel الخاص بك.
    *   سيقوم P3CC بعد ذلك بمعالجة المِلَفّات، مع عرض شريط تقدم.
    *   عند الانتهاء، سيقوم بإنشاء ملف إخراج `.p3` جديد في نفس دليل ملفات المصدر `.p3` الخاصة بك، باسم المجلد المصدر (على سبيل المثال، `My P3 Files.p3` يصبح `My_P3_Files.p3`).

## التكوين (`config.py`)

ملف `config.py` هو المكان المركزي لجميع إعدادات البرنامج. يمكنك تعديله لتكييف P3CC مع هياكل البيانات المختلفة أو متطلبات الإخراج.

### الأقسام الرئيسية للتعديل:

#### 1. `ENCODING`
- **الغرض**: يحدد ترميز الأحرف لقراءة وكتابة ملفات `.p3`.
- **مثال**: `ENCODING = 'cp1256'` (شائع لبيئات ويندوز العربية)

#### 2. `CARD_FILE_EXT`
- **الغرض**: يحدد امتداد المِلَفّ لملفات بيانات البطاقة.
- **مثال**: `CARD_FILE_EXT = 'p3'`

#### 3. `PROFILE_SIGNATURES`
- **الغرض**: يربط أسماء المِلَفّات الشخصية بقائمة من أسماء الأعمدة التي *يجب* أن تكون موجودة في ملف Excel ليتم اكتشاف هذا المِلَفّ الشخصي. ترتيب المِلَفّات الشخصية في هذا القاموس مهم؛ سيتم تحديد أول ملف شخصي مطابق.
- **كيفية الإضافة/التعديل**:
    *   لإضافة ملف شخصي جديد، أضف إدخالًا جديدًا إلى هذا القاموس.
    *   المفتاح هو اسم المِلَفّ الشخصي الذي اخترته (على سبيل المثال، `'my_new_profile'`).
    *   القيمة هي قائمة برؤوس الأعمدة الهامة التي تحدد هذا المِلَفّ الشخصي بشكل فريد في ورقة Excel الخاصة بك.
- **مثال**:
```python
PROFILE_SIGNATURES = {
    'classic': ['Card No'],
    'yalla':   ['Mobile Number'],
    'zamalek': ['رقم بطاقة الصراف الالى'],
    'my_new_profile': ['Unique Column A', 'Unique Column B'],
}
```

#### 4. `FIELD_MAP`
- **الغرض**: يحدد كيفية تعيين البيانات من مِلَفّ Excel الخاص بك إلى مِلَفّ الإخراج `.p3` لكل مِلَفّ شخصي مكتشف. كل إدخال هو tuple: `(output_tag, col_def, processor_key)`.
- **كيفية الإضافة/التعديل**:
    *   **`output_tag` (سلسلة نصية)**: العلامة التي ستتم كتابتها إلى مِلَفّ `.p3` (على سبيل المثال، `'<arabic>'`, `'<MobileNumber>'`).
    *   **`col_def` (سلسلة نصية، قائمة سلاسل نصية، `None`، أو `'__line_count__'`)**:
        *   **سلسلة نصية**: اسم عمود مباشر من ورقة Excel الخاصة بك (على سبيل المثال، `'CardHolder Name'`).
        *   **قائمة سلاسل نصية**: قائمة بأسماء الأعمدة الاحتياطية. سيحاول البرنامَج كل اسم بالترتيب، ويستخدم أول اسم يجده (على سبيل المثال، `['الاسم', 'الإســــــم']`).
        *   **`None`**: يشير إلى أنه لا يتم استخدام قيمة عمود محددة؛ ستتم كتابة العلامة بقيمة فارغة (على سبيل المثال، لـ `<address>` إذا لم يكن العنوان موجودًا في Excel).
        *   **`'__line_count__'`**: علامة خاصة تقوم بإدخال عداد البطاقات الحالي (رَقَم السطر) في الإخراج. تستخدم للقيم الديناميكية غير الموجودة في Excel.
    *   **`processor_key` (سلسلة نصية أو `None`)**:
        *   مفتاح سلسلة نصية يشير إلى دالة معالجة البيانات المعرفة في `_PROCESSOR_REGISTRY` في `utils.py`.
        *   المفاتيح الشائعة تشمل:
            *   `'col_check'`: يطبق `col_check` (يعالج قيم NaN/None، ويزيل المسافات البيضاء).
            *   `'chr_replace'`: يطبق `chr_replace` (يطبع الأحرف العربية).
            *   `'jpg'`: يضيف `.JPG` إلى القيمة.
        *   **`None`**: إذا كانت `None`، فسيتم تحويل القيمة ببساطة إلى سلسلة نصية دون أي معالجة خاصة.

- **مثال (إضافة حقل جديد إلى ملف شخصي موجود)**:
    لنفترض أنك ترغب في إضافة حقل جديد `<Email>` إلى ملف تعريف `yalla`، وعموده في Excel هو `Email Address`.
```python
FIELD_MAP = {
    'yalla': [
        # ... الحقول الموجودة ...
        ('<address>',       'Address',                      None),
        ('<city>',          'City',                         None),
        ('<Email>',         'Email Address',                None), # حقل جديد
    ],
    # ... ملفات تعريف أخرى ...
}
```

- **مثال (إضافة مِلَفّ شخصي جديد)**:
    إذا أضفت `'my_new_profile'` إلى `PROFILE_SIGNATURES`، فستقوم بعد ذلك بتعريف تعيين الحقول الخاص به:
```python
FIELD_MAP = {
    # ... ملفات تعريف موجودة ...
    'my_new_profile': [
        ('<ID>',            'Unique Column A',              None),
        ('<Name>',          'Customer Name',                'chr_replace'),
        ('<Status>',        'Account Status',               'col_check'),
        ('<Counter>',       '__line_count__',               None),
    ],
}
```

## معالجة الأخطاء (`exceptions.py`)

يحدد مِلَفّ `exceptions.py` فئات استثناءات مخصصة تُستخدم في جميع أنحاء تطبيق P3CC لظروف خطأ محددة. يتيح ذلك معالجة أخطاء أكثر دَقَّة ويوفر رسائل خطأ أوضح وأكثر وصفية، مما يساعد في تصحيح الأخطاء واستكشافها.

-   **`P3CCError`**: الاستثناء الأساسي لجميع الأخطاء المخصصة في P3CC. ترث جميع الاستثناءات المخصصة الأخرى من هذا الاستثناء.
-   **`ProfileDetectionError`**: يُثار عندما لا يتمكن البرنامَج من تحديد مِلَفّ تعريف مطابق لملف Excel المقدم بناءً على `PROFILE_SIGNATURES` في `config.py`.
-   **`SourceFilesError`**: يُثار عندما لا يتم العثور على ملفات مصدر `.p3` في الدليل المحدد.
-   **`MissingColumnError`**: يُثار عندما يكون عمود مطلوب (كما هو محدد في `FIELD_MAP` أو `PROFILE_SIGNATURES`) مفقودًا من بيانات Excel.
-   **`InvalidCardError`**: يُثار عندما تكون بيانات البطاقة مشوهة أو لا تفي بالمعايير المتوقعة في أثناء المعالجة.
