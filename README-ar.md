# P3CC (P3 Collect-Comparative)

## نَظْرَة عامة

P3CC هو تطبيق سطح مكتب على ويندوز يقوم بدمج بيانات حاملي البطاقات من جدول بيانات Excel في ملفات إصدار البطاقات `.p3`. يقوم بمسح ملفات `.p3` المصدر بحثًا عن علامات رقم البطاقة، والبحث عن صف Excel المطابق، وإدراج الحقول الموسومة (اسم حامل البطاقة، الرقم القومي، رقم الهاتف المحمول، وبيانات أخرى خاصة بالمِلَفّ الشخصي) في الإخراج قبل علامة `#END#` الخاصة بكل سجل بطاقة.

يُشحَن التطبيق كواجهة رسومية مبنية على Tkinter ومُعبَّأة في مِلَفّ تنفيذي مستقل `P3CC.exe` (عبر PyInstaller) — لا يحتاج المستخدم النهائي إلى تثبيت بايثون إطلاقًا ولا يتعامل مع أي محطة طرفية (Terminal).

يتكون البرنامَج من وحدات بايثون التالية (وضع المصدر/التطوير فقط — لا شيء من هذا مطلوب لتشغيل المِلَفّ التنفيذي المُعبَّأ):
- `app.py`: نقطة دخول الواجهة الرسومية — هذا ما يقوم PyInstaller بتعبئته في `P3CC.exe`.
- `gui.py`: كامل واجهة Tkinter — النافذة الرئيسية، مربع حوار الإعدادات، مربع حوار إدارة الحقول، شريط التقدم، لوحة النتائج.
- `main.py`: ينسق اكتشاف المِلَفّات، وتحميل Excel، واكتشاف المِلَفّ الشخصي، وتوليد الإخراج عبر `run_pipeline()`. كما يوفر نقطة دخول طرفية بسيطة (`python main.py`) لتصحيح أخطاء خط المعالجة أثناء التطوير.
- `utils.py`: دوال مساعدة بحتة لتحويل البيانات، ومعالجة المِلَفّات، واكتشاف المِلَفّات الشخصية، وبناء النصوص.
- `config.py`: ثوابت خاصة بالمطورين فقط — الترميز، العلامات الثنائية، توقيعات المِلَفّات الشخصية، وتعيينات الحقول الافتراضية الأساسية.
- `settings.py` / `field_map_store.py`: تحميل وحفظ `settings.json` (المجلدات المحفوظة) و`field_map.json` (تعيينات عمود Excel ← علامة `.p3`) القابلين للتعديل من قِبَل المستخدم، بجانب المِلَفّ التنفيذي قيد التشغيل.
- `exceptions.py`: يحدد فئات الاستثناءات المخصصة لظروف خطأ محددة، مما يسمح بمعالجة أخطاء أكثر دقة وتصحيح أخطاء أوضح.

## الميزات

- **تعبئة محمولة بلا تثبيت**: يعمل كـ `dist/P3CC/P3CC.exe` على أي جهاز ويندوز، دون الحاجة لتثبيت بايثون. وزّع مجلد `P3CC` بالكامل كوحدة واحدة، وليس المِلَفّ التنفيذي فقط.
- **المعالجة القائمة على المِلَفّ الشخصي**: يكتشف تلقائيًا بنية ملف Excel (مثل `yalla`، `zamalek`، `classic`) ويطبق تعيين البيانات الصحيح.
- **بحث فعال عن البيانات**: يستخدم Pandas DataFrames مع عمليات بحث مفهرسة لاسترجاع سريع لبيانات البطاقة.
- **تطبيع الأحرف العربية**: يطبّع الأرقام الهندية العربية الشرقية وبعض الرموز الخاصة لإخراج آمن بترميز `cp1256`.
- **تعيينات حقول قابلة للتعديل من قِبَل المستخدم**: يتيح مربع حوار "إدارة الحقول" في الواجهة الرسومية إضافة/تعديل/حذف/إعادة ترتيب تعيينات عمود Excel ← علامة `.p3` لكل مِلَفّ شخصي — دون الحاجة لتعديل أي كود عند إضافة العميل عمودًا جديدًا في Excel أو حذفه.
- **تذكّر المجلدات**: يتذكر مربع حوار الإعدادات آخر مجلدي مصدر وExcel تم استخدامهما.
- **تتبع التقدم ولوحة النتائج**: شريط تقدم أثناء المعالجة، ثم ملخص (المِلَفّات المعالَجة، البطاقات المقروءة/المكتوبة/المتخطاة، الوقت المستغرق، مسار الإخراج) مع زر "فتح مجلد الإخراج".
- **التسجيل (Logging)**: تسجيل مفصل في `p3cc.log` بجانب التطبيق لتحسين التتبع وتصحيح الأخطاء.

## كيفية الاستخدام (للمستخدم النهائي)

1. احصل على مجلد `P3CC` (الذي يحتوي على `P3CC.exe` وملفاته المساعدة) — انسخ المجلد بالكامل، وليس المِلَفّ التنفيذي فقط.
2. انقر نقرًا مزدوجًا على `P3CC.exe`.
3. **Choose Folder…** — اختر المجلد الذي يحتوي على ملفات `.p3` المصدر الخاصة بك.
4. **Choose File…** — اختر ملف بيانات Excel الخاص بك (`.xlsx` أو `.xls`).
5. اضغط **Run**. سيتتبع شريط تقدم عملية المعالجة؛ وعند الانتهاء سترى ملخص النتائج وزر **Open Output Folder**.
6. تتم كتابة مِلَفّ `.p3` الناتج في نفس مجلد ملفات المصدر، باسم ذلك المجلد (مثال: مجلد باسم `My P3 Files` ينتج عنه `My_P3_Files.p3`).

استخدم **Settings** لتغيير المجلدات الافتراضية التي تفتح عندها نافذتا اختيار المِلَفّات. استخدم **Manage Fields** لإضافة أو تعديل أو حذف أو إعادة ترتيب أي عمود من Excel يغذي أي علامة في `.p3` للمِلَفّ الشخصي النشط، دون لمس أي كود — انظر [تعيينات الحقول](#تعيينات-الحقول-مربع-حوار-إدارة-الحقول) أدناه.

## التشغيل من المصدر (للمطورين)

```bash
pip install -r requirements-dev.txt   # تبعيات التشغيل + pyinstaller
python app.py                         # تشغيل الواجهة الرسومية
python main.py                        # نقطة دخول طرفية لتصحيح أخطاء خط المعالجة (لا تزال تستخدم نوافذ Tk لاختيار المِلَفّات)
toolkit.bat                           # غلاف بقائمة تفاعلية: run / test / check / setup / package
```

راجع `CLAUDE.md` للحصول على ملاحظات المعمارية الكاملة، وتعليمات البناء، وتفاصيل تنسيق مِلَفّ `.p3`.

## تعيينات الحقول (مربع حوار إدارة الحقول)

تتم التغييرات اليومية على العمود الذي يغذي كل علامة في `.p3` من الواجهة الرسومية، وليس بتعديل الكود:

1. افتح **Manage Fields** من النافذة الرئيسية.
2. اختر المِلَفّ الشخصي المراد تعديله من القائمة المنسدلة.
3. **Add…** / **Edit…** لحقل: أعطه علامة (مثل `<address>`)، ومصدر قيمة (عمود Excel، أو قائمة أعمدة احتياطية مفصولة بفواصل، أو عداد البطاقات الحالي، أو فارغ)، وتحويلًا اختياريًا (إزالة القيم الفارغة/غير المتوفرة، تطبيع الأحرف العربية، أو إضافة `.JPG`).
4. **Move Up** / **Move Down** لإعادة الترتيب، **Delete** لحذف حقل.
5. **Reset Profile to Defaults** يعيد التعيين الافتراضي المدمج لهذا المِلَفّ الشخصي إذا أردت البدء من جديد.
6. **Save & Close** يكتب التغيير إلى `field_map.json` بجانب المِلَفّ التنفيذي — ويصبح ساري المفعول في التشغيلة التالية دون الحاجة لإعادة التشغيل.

## التكوين للمطورين (`config.py`)

يحتوي `config.py` على الثوابت التي تحدد عقد بيانات الإخراج — أي تعديل خاطئ هنا قد يُفسد إخراج البطاقات بصمت، لذا فهو تعديل خاص بالمطورين فقط، وليس مكشوفًا في الواجهة الرسومية.

#### 1. `ENCODING`
- **الغرض**: ترميز الأحرف لقراءة وكتابة ملفات `.p3`.
- **القيمة**: `ENCODING = 'cp1256'` (شائع في بيئات ويندوز العربية).

#### 2. `CARD_FILE_EXT`
- **الغرض**: امتداد المِلَفّ لملفات بيانات البطاقة.
- **القيمة**: `CARD_FILE_EXT = 'p3'`.

#### 3. `PROFILE_SIGNATURES`
- **الغرض**: يربط اسم المِلَفّ الشخصي بأعمدة Excel التي يجب أن تكون كلها موجودة لتحديده، وبعمود مفتاح البحث عن رقم البطاقة. ترتيب القاموس مهم — أول مِلَفّ شخصي مطابق هو الذي يُختار.
- **كيفية إضافة مِلَفّ شخصي**: أضف إدخالًا بقائمة `signatures` و`lookup_col`، ثم أضف إدخالًا مطابقًا في `FIELD_MAP` أدناه ليكون هناك بيانات أولية عند فتح إدارة الحقول لأول مرة لهذا المِلَفّ الشخصي.
- **المِلَفّات الشخصية الحالية**:
```python
PROFILE_SIGNATURES = {
    'yalla': {
        'signatures': ['Card No', 'Mobile Number'],
        'lookup_col': 'Card No',
    },
    'classic': {
        'signatures': ['Card No'],
        'lookup_col': 'Card No',
    },
    'zamalek': {
        'signatures': ['رقم بطاقة الصراف الالى'],
        'lookup_col': 'رقم بطاقة الصراف الالى',
    },
    'my_new_profile': {
        'signatures': ['Unique Column A', 'Unique Column B'],
        'lookup_col': 'Unique Column A',
    },
}
```

#### 4. `FIELD_MAP`
- **الغرض**: البيانات الأولية المدمجة لتعيينات حقول كل مِلَفّ شخصي — ما يبدأ منه التثبيت الجديد، وما يستعيده زر "Reset to Defaults" في إدارة الحقول. كل إدخال هو tuple: `(output_tag, col_def, processor_key)`.
    - **`output_tag`**: العلامة التي تُكتب إلى مِلَفّ `.p3` (مثل `'<arabic>'`, `'<MobileNumber>'`).
    - **`col_def`**: اسم عمود Excel (`str`)، أو قائمة أعمدة احتياطية (أول عمود موجود يُستخدم)، أو `None` (تُكتب العلامة فارغة)، أو `'__line_count__'` (يُدرج عداد البطاقات الحالي).
    - **`processor_key`**: مفتاح إلى سجل المعالجات في `utils.py` — `'col_check'` (يزيل المسافات ويعالج القيم الفارغة)، `'chr_replace'` (يطبّع الأحرف العربية)، `'jpg'` (يضيف `.JPG`) — أو `None` لتحويل نصي بسيط.
- **مثال** — ملف تعريف `yalla` الفعلي:
```python
FIELD_MAP = {
    'yalla': [
        ('<arabic>', 'CardHolder Name', None),
        ('<national>', 'NID', 'col_check'),
        ('<postoffice>', 'Post Office Name2', 'chr_replace'),
        ('<region>', 'Post Region', 'col_check'),
        ('<barcode>', 'Barcode', None),
        ('<ClientNo>', 'Client No', None),
        ('<MobileNumber>', 'Mobile Number', None),
        ('<IssuanceDate>', 'Issue Date', None),
        ('<address>', 'Address', None),
        ('<city>', 'City', None),
    ],
    # 'classic' و'zamalek' يتبعان نفس الشكل.
}
```

## معالجة الأخطاء (`exceptions.py`)

يحدد مِلَفّ `exceptions.py` فئات استثناءات مخصصة تُستخدم في جميع أنحاء تطبيق P3CC لظروف خطأ محددة، مما يسمح بمعالجة أخطاء أكثر دقة ويوفر رسائل أوضح وأكثر وصفًا.

- **`P3CCError`**: الاستثناء الأساسي لجميع الأخطاء المخصصة في P3CC. ترث منه جميع الاستثناءات المخصصة الأخرى.
- **`ProfileDetectionError`**: يُثار عندما لا يطابق أي توقيع في `PROFILE_SIGNATURES` ملف Excel المُقدَّم.
- **`SourceFilesError`**: يُثار عندما لا يتم العثور على ملفات مصدر `.p3` في الدليل المحدد.
- **`MissingColumnError`**: يُثار عندما يكون عمود مطلوب (من `FIELD_MAP` أو `PROFILE_SIGNATURES`) مفقودًا من بيانات Excel.
- **`InvalidCardError`**: يُثار عندما تكون بيانات البطاقة مشوهة أو لا تفي بالمعايير المتوقعة أثناء المعالجة.

## هيكل المشروع

```
p3cc/
├── app.py               # نقطة دخول الواجهة الرسومية — هذا ما يعبئه PyInstaller
├── gui.py                # واجهة Tkinter: النافذة الرئيسية، الإعدادات، إدارة الحقول
├── main.py               # تنسيق خط المعالجة + نقطة دخول طرفية للتطوير
├── utils.py               # دوال مساعدة بحتة
├── config.py              # ثوابت خاصة بالمطورين، توقيعات المِلَفّات الشخصية، تعيين الحقول الأولي
├── settings.py            # تحميل/حفظ settings.json
├── field_map_store.py     # تحميل/حفظ field_map.json
├── exceptions.py          # تعريفات الاستثناءات المخصصة
├── P3CC.spec              # مواصفات بناء PyInstaller (مُثبَّتة في المستودع — تحافظ على إصلاحات الاستيراد الخفي)
├── requirements.txt       # تبعيات التشغيل
├── requirements-dev.txt   # تبعيات التشغيل + PyInstaller (لبناء المِلَفّ التنفيذي)
├── run.bat                # خاص بالمطورين فقط: يُفعِّل .venv ثم يشغل python main.py
├── toolkit.bat            # غلاف بقائمة تفاعلية: run / test / check / setup / package
└── README.md              # هذه الوثائق
```
